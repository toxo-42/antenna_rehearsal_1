# P6 — SAA-2 USB 측정 (2차 개발 22:10~23:10)

`src/saa2.py`에 `SweepSource` 구현을 만들어 줘. 대상 장비는 SAA-2(NanoVNA V2 계열, HW V2_2, 펌웨어 1.2)다. 아래 통신은 2026-11-22에 실물로 확인한 것이다(macOS, `/dev/cu.usbmodem*`).

## 통신
- pyserial, 115200, timeout 0.5, write_timeout 2. 포트 목록에서 VID 0x04B4 / PID 8을 맨 앞에 둔다
- 식별: 입력 버퍼를 비우고 `00` 8바이트 + `0D`를 쓰면 3초 안에 `'2'` 1바이트
- 범위 설정(리틀엔디언): 시작 Hz `23 00` + 8바이트, 간격 Hz `23 10` + 8바이트, 점 개수 `21 20` + 2바이트, 주파수당 값 1개 `21 22 01 00`. 간격 = (종료 - 시작) / (점 개수 - 1). 0.5초 기다린 뒤 `20 30 00`으로 FIFO를 비운다
- 읽기: `18 30 n`(n은 1~255)을 쓰면 32바이트 패킷 n개
- 패킷: 리틀엔디언 `<6iH`를 오프셋 0에서. 순서는 기준(re, im), S11(re, im), S21(re, im), 인덱스. `S11 = S11채널 / 기준`. 기준이 0이면 오류. S21은 버린다
- 모으기: 패킷을 인덱스 자리에 넣고, 0부터 점 개수 - 1까지 모두 차면 완료. 인덱스 >= 점 개수이면 오류. 전체 40초 제한(실측: 201점 4.4초, 291점 10.5초). 다 못 받으면 부분 데이터를 저장하지 않는다
- 입력 검사: 시작 < 종료, 50 kHz~3 GHz, 점 개수 11~1001. 축의 각 주파수는 정수 Hz로 반올림한다. 저장(`f_hz`)했다가 다시 읽은 스윕이 측정한 스윕과 같아야 하고, 이것을 테스트한다

## 이 장비에서 알아 둘 것
- **PC가 범위를 정한다.** 장비 화면의 설정은 쓰이지 않는다. 화면과 같은지 묻는 확인은 두지 않는다
- **읽기 명령을 보내면 장비 화면이 "USB MODE"로 바뀌고 조작이 멈춘다.** 전원을 껐다 켜면 돌아온다. 측정 버튼 옆에 이 안내를 보여 준다. 식별과 화면 받기만으로는 화면이 멈추지 않는다
- **USB로 받는 값에는 장비의 교정이 반영되지 않는다.** `source = usb`인 측정은 요청 값과 관계없이 `cal_mode = unknown`으로 저장한다(카드에 uncalibrated가 붙는다)
- 종료 주파수가 목표의 1.5배보다 작거나 시작이 목표의 0.5배보다 크면 경고한다. 공진이 범위 끝에 가까우면 깊이가 3 dB 미만으로 계산되어 놓칠 수 있다
- 장비 레지스터에 쓰는 것은 위의 범위 설정 4개와 FIFO 비우기뿐이다. 교정 레지스터나 다른 주소에는 쓰지 않는다

만든 스윕은 다른 source와 같이 `service`의 스윕 검사를 거친다(빈 복소값 목록, 허용 범위 밖의 값 포함).

API: `GET /api/ports`, `POST /api/measurements`의 `source=usb`(포트, 시작 MHz, 종료 MHz, 점 개수). 측정 중 중복 요청은 409. 어떤 오류에서도 포트를 닫는다.

## 시간이 남으면: 장비 화면 받기
`GET /api/device/screen?port=`: `20 EE 00`을 쓰면 `<HHB`(폭, 높이, 비트 수 16) 5바이트와 폭×높이×2바이트의 RGB565가 온다(이 장비는 320×240). PNG로 바꿔 돌려준다. 읽기 명령 전에 받아야 측정 화면이 찍히고, USB MODE가 된 뒤에는 그 글자만 찍힌다.

통과 검사: 가짜 포트로 정상 / 식별 실패 / 범위 밖 인덱스 / 시간 초과 / 기준 0 테스트, 범위 설정으로 쓴 바이트가 위와 같은지(2000~3000 MHz, 201점이면 `23 00 00 94 35 77 00 00 00 00`, `23 10 40 4b 4c 00 00 00 00 00`, `21 20 c9 00`, `21 22 01 00`, `20 30 00`), 그리고 **실물 1회 측정이 저장됨**(안 되면 안 됐다고 보고). 2.45 GHz 패치를 2000~3000 MHz, 201점으로 재면 공진이 2445 MHz 근처(±10)에 나온다.
