# P7 — 이력과 전후 비교 (90분)

`src/compare.py`와 `GET /api/compare?before=&after=`, 이력 화면을 만들어 줘.

- 같은 안테나의 측정끼리만 비교한다(목표는 안테나에 저장되므로 같다). 아니면 422
- 결과: 공진 이동(MHz), 목표와의 거리 변화, 공진점 S11 변화, 대역폭 변화, 단계 변화, after의 change_note
- 판정은 코드가 한다. 목표와의 거리 변화가 측정 간격보다 작으면 "차이 없음(측정 간격 이내)", 줄면 "가까워짐", 늘면 "멀어짐". 공진이 한쪽이라도 없거나 한쪽 stage가 `invalid`이면 "비교 불가"와 이유
- 원인을 단정하지 않는다. "무엇을 바꾼 뒤 이렇게 됐다"까지만 쓴다
- 화면: 측정 순서별 공진 주파수와 목표선, 두 스윕 겹쳐 보기. change_note는 부품(도체/접지판/케이블/교정/납땜/없음), 동작(줄임/늘림/변경/없음), 수치·단위 **선택 상자**로 입력받는다 (LLM으로 메모를 해석하지 않는다)

통과 검사: offtarget_low(381.25) → good(430.75), 목표 433이면 이동 +49.5 MHz, "가까워짐". 같은 측정끼리는 "차이 없음". 공진 없는 측정은 "비교 불가". 합성 2000건에서 이력 조회 시간을 재서 보고.
