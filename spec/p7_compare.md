# P7 — 이력과 전후 비교 (40분)

`src/compare.py`와 `GET /api/compare?before=&after=`, 이력 화면을 만들어 줘.

- 같은 안테나의 측정끼리만 비교한다(목표는 안테나에 저장되므로 같다). 아니면 422. 없는 id는 404
- 결과: 공진 이동(MHz), 목표와의 거리 변화, 공진점 S11 변화, 대역폭 변화, 단계 변화, after의 change_note
- 목표와의 거리는 절댓값이다(공진이 목표를 건너가도 거리로 비교한다)
- 측정 간격: 각 측정에서 공진점 양옆 간격 중 큰 값, 두 측정 중 큰 쪽(스윕 전체 평균이 아니다. 간격이 고르지 않은 CSV에서 공진 근처가 촘촘할 수 있다). 공진이 없으면 null
- 판정은 코드가 한다. 목표와의 거리 변화가 측정 간격보다 작으면 "차이 없음(측정 간격 이내)", 줄면 "가까워짐", 늘면 "멀어짐". 공진이 한쪽이라도 없거나 한쪽 stage가 `invalid`이면 "비교 불가"와 이유("이전 측정(N번)…" 또는 "이후 측정(N번)…"으로 시작, 공진이 없을 때는 "목표 근처의 공진이 없습니다"). 이때 수치 변화는 모두 null
- 원인을 단정하지 않는다. "무엇을 바꾼 뒤 이렇게 됐다"까지만 쓴다. 요약 문장에 "때문", "원인" 같은 말이 없는지 테스트한다
- change_note는 "부품 [동작] [수치 단위]" 꼴의 문자열로 저장한다(예: "도체 줄임 5 mm"). 서버가 이 형식을 검사해(`src/change_note.py`), 형식에 맞는 메모만 요약 문장에 넣는다. 형식이 아닌 메모(API로 들어온 자유 글)는 요약에 넣지 않고 필드와 표에만 남긴다. 부품·동작·단위 목록과 수치 형식(직접 입력: 0보다 큰 수, 정수 4자리·소수 2자리까지)은 Python과 TS가 같은지 테스트한다
- 응답 필드: `before_id, after_id, target_mhz, step_mhz, comparable, verdict, reasons, shift_mhz, distance_before_mhz, distance_after_mhz, distance_change_mhz, s11_change_db, bandwidth_change_pct, stage{before, after}, change_note, summary`
- 요약 문장: "'{메모}' 변경 뒤 공진이 381.25 → 430.75 MHz (+49.50 MHz)로 바뀌었고, 목표 433 MHz까지 거리는 51.75 → 2.25 MHz입니다: 가까워짐." 메모가 비었으면 앞부분을 "이후 측정(N번)에 기록된 변경이 없습니다."로, 형식에 맞지 않는 메모면 "이후 측정(N번)의 메모는 선택 상자 형식이 아니라 요약에 넣지 않았습니다."로 바꾼다. 비교 불가면 "비교 불가: {이유}"
- 같은 측정끼리 비교하면 요약은 "같은 측정(N번)끼리 비교했습니다"로 쓴다
- 화면 순서: 추이 그래프 → 전후 비교 → 측정 표와 카드. 처음에는 마지막 두 측정이 골라져 있다(한 건뿐이면 같은 측정 둘). 고르는 목록의 항목은 "3번째 · 합성 데이터 · 시각 · 변경 기록 없음"처럼 쓴다. 결과는 출처 배지 줄(이전 → 이후), 판정 한 줄, 이유, 표(공진 이동, 목표와의 거리, 거리 변화, 공진점 S11 변화, 대역폭 변화(%p), 단계, 바꾼 것. 부호 붙은 소수 2자리, 없으면 "—"나 "기록 없음"), 요약 문장, "이 비교는 무엇을 바꾼 뒤 어떻게 됐는지만 보여 주며, 원인을 판단하지 않습니다." 순서다. 이력 표에는 "바꾼 것" 열이 더 붙는다
- 화면: 측정 순서별 공진 주파수와 목표선, 두 스윕 겹쳐 보기. change_note는 "지난 측정 뒤 바꾼 것"이라는 이름으로 부품(도체/접지판/케이블/교정/납땜/없음), 동작(줄임/늘림/변경/없음), 단위(mm/cm/%)는 **선택 상자**, 수치는 **직접 입력**으로 받는다(0보다 큰 수, 정수 4자리·소수 2자리까지. 그 밖의 글은 기록에 넣지 않고 "숫자만 입력"이라고만 알린다. LLM으로 메모를 해석하지 않는다). 두 곳 모두 아래에 "저장될 기록: 도체 줄임 5 mm"처럼 보여 주고(없으면 "저장될 기록: 없음". 문장은 한 함수가 만든다), 부품이 "없음"이면 기록하지 않는다. 이 입력은 두 곳에 같은 값으로 둔다: 측정 화면의 행(Calibration과 측정 방법 사이)과 판정 화면의 "다음 측정" 띠(p6). 측정 중에는 잠그고, 측정이 성공하면 비운다(도체 길이는 비우지 않는다)
- 합성 데이터 표시(원칙 3)는 이 화면에도 적용한다: 추이 그래프의 점 모양과 범례, 비교 선택 목록의 항목, 겹쳐 보기의 범례
- 이력은 한 번에 200건까지만 받는다. 잘렸으면 그렇다고 표시하고 번호는 "최근 200건 중 N번째"로 쓴다

통과 검사: offtarget_low(381.25) → good(430.75), 목표 433이면 이동 +49.5 MHz, "가까워짐". 같은 측정끼리는 "차이 없음". 공진 없는 측정은 "비교 불가"(이전 쪽·이후 쪽, 공진 없음·`invalid` 각각). 공진이 목표보다 높은 경우(445 → 438 "가까워짐")와 목표를 건너는 경우(440 → 426, 거리 7 → 7 "차이 없음"). 간격이 다른 두 측정을 순서를 바꿔 비교해도 큰 쪽 간격으로 판정. 합성 2000건에서 이력 조회 시간을 재서 보고.

리허설 1(2026-11-22): 약 18분. 2000건에서 목록 한 페이지(200건) 약 6 ms, 비교 약 1.2 ms. 위의 간격 정의·절댓값·메모 형식 검사·합성 표시는 reviewer와 `second-opinion`에서 나와 고친 것이다.
