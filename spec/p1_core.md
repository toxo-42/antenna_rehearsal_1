# P1 — 판정 코어 (50분)

`src/models.py`, `tolerance.py`, `sweep_parser.py`, `resonance.py`, `classify.py`, `impedance.py`, `synthetic.py`를 만들어 줘. 테스트를 먼저 써.

## 입력
CSV 헤더 `Frequency_Hz,S11_dB` 필수, `S11_real,S11_imag` 선택. 다른 열은 무시. 주파수는 오름차순, 3점 이상, 유한한 수. 어기면 한국어 메시지로 ValueError. 행에서 생긴 오류는 메시지에 행 번호를 넣는다.
- 오름차순은 엄격하게 본다. 같은 주파수가 연달아 나오면 거부
- 줄바꿈은 LF, CRLF, CR 단독을 모두 받는다. 맨 앞의 BOM, 빈 줄, 구분자만 있는 행(`,`)은 건너뛴다
- 위 네 열 이름 중 하나가 헤더에 두 번 나오면 거부. 무시하는 열은 중복되어도 된다
- 닫히지 않은 따옴표는 거부한다(뒤의 행을 삼키지 않게)
- `S11_real`, `S11_imag` 중 하나만 있으면 복소값이 없는 것으로 본다
- 허용 범위(경계 포함): 주파수 1 Hz~1 THz, `S11_dB` -1000~1000, `S11_real`·`S11_imag` -1000~1000. 벗어나면 거부한다. 이 범위 안이면 판정이 만드는 값이 모두 유한하다

## 경계 비교
이 문서의 "이상", "이하", "안"은 모두 경계를 포함한다. 뺄셈 결과가 `2.9999999999999996`처럼 어긋나 경계에서 판정이 바뀌지 않도록, `tolerance.py`에 `at_least(value, limit)`와 `at_most(value, limit)`를 두고(상대·절대 오차 `1e-9`) 아래 비교에 모두 쓴다: 깊이 3 dB와 2 dB, S11 -6 dB, 정합 기준, 후보 창 ±20 %, 대역 안에 목표가 있는지, 통상 대역폭, 측정 간격의 절반.

## 공진 탐지
- 지역 최솟값: `v[i] < v[i-1]` 그리고 `v[i] <= v[i+1]`
- 깊이(prominence): 좌우 각각 더 낮은 점이 나오기 전까지의 최고점을 구하고, 둘 중 낮은 쪽에서 `v[i]`를 뺀 값
- **공진**: 깊이 >= 3 dB 그리고 S11 <= -6 dB. **약한 딥**: 공진이 아니면서 깊이 >= 2 dB. 나머지는 개수만 센다
- 정합 대역: 공진을 포함해 S11 <= 정합 기준(기본 -10 dB)인 연속 구간. 경계는 선형 보간. 기준보다 얕으면 없음. 정합 기준은 `models.py`의 상수 하나로 두고, 이번에는 화면·API에서 바꾸지 않는다
- 대역폭 % = 대역 폭 / 공진 주파수 * 100
- 깊이와 정합 대역은 점 수에 비례하는 시간에 구한다(골짜기마다 양옆을 끝까지 다시 걷지 않는다). 60,000점 지그재그 스윕(-1/-5 dB 반복, -11/-15 dB 반복)을 각각 2초 안에 처리하는 테스트를 둔다

## 단계 판정 (목표의 ±20 % 안의 공진만 후보)
1. 후보 없음 → `none`
2. 대역 안에 목표가 있는 후보를 우선, 없으면 목표에 가장 가까운 후보를 고른다
3. 정합 대역이 없음(S11이 정합 기준보다 큼) → `unmatched`. 정합 기준을 여기서 다시 비교하지 않는다
4. 목표가 대역 밖 → `offtarget`
5. 대역폭 < 통상값(모노폴 8 %, 패치 2.5 %) → `narrow`
6. 목표가 대역 경계에서 측정 간격의 절반보다 가까움 → `offtarget`. 측정 간격은 스윕 전체 평균이 아니라 **그 경계를 감싸는 두 측정점의 간격**이다(경계가 스윕 끝이면 마지막 두 점). 정확히 절반이면 가깝지 않은 것으로 본다
7. 나머지 → `good`

`offset_pct = (공진 - 목표) / 목표 * 100`. 선택된 것 외의 공진은 **목표와의 거리 순**으로 정렬해 돌려준다.

## 임피던스
`Z = 50 * (1 + g) / (1 - g)`. 공진점의 R, X와, 저주파 10 % 점들의 `g` 실수부 평균(`low_freq_gamma_real`). 점 수는 `max(1, 내림(점 개수 * 0.1))`. 복소값이 없으면 None. `g`가 정확히 1이면 R은 무한대, X는 0.

## 합성 데이터와 기대값

통과 검사: 위 18행을 전부 검사하는 테스트 통과. 기대값은 고치지 마. 어긋나면 어느 규칙 때문인지 보고하고 멈춰.

18행만으로는 규칙이 고정되지 않는다. 아래 경계 테스트도 둔다.
- 단계 순서: 4단계가 5단계보다 먼저, 5단계가 6단계보다 먼저 적용되는 경우 각각
- 후보 창: 정확히 ±20 %인 공진은 후보(433 MHz에서 346.4와 519.6 둘 다), 20 %를 조금 넘으면 후보 아님
- 공진: 깊이가 정확히 3 dB, S11이 정확히 -6 dB, 약한 딥 깊이가 정확히 2 dB인 경우는 포함. 조금 모자라면 제외
- 대역: S11이 정확히 정합 기준이면 정합. 대역폭이 정확히 통상값이면 `narrow`가 아님. 보간된 대역 경계 위의 목표는 대역 안
- 6단계: 여유가 간격의 1/4~1/2 사이면 `offtarget`, 정확히 절반이면 아님, 간격이 고르지 않은 스윕에서 경계 쪽 간격을 쓰는지
- 저주파 10 %: 25점이면 2점

테스트를 다 쓴 뒤, 아래를 하나씩 틀리게 바꿔 테스트가 실패하는지 확인하고 되돌려 줘(바꾼 채로 두지 마): 4·5단계 순서 교체, 후보 창 21 %, 통상 대역폭 모노폴 9 %와 패치 3 %, 깊이 3.01 dB, S11 -6.01 dB, 약한 딥 2.01 dB, 6단계의 절반을 1/4로. 통과해 버리는 것이 있으면 테스트를 보강해.
