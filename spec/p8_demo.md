# P8 — 시연 모드 (60분)

`APP_MODE=demo`를 추가해 줘.
- `antenna.db`가 아니라 `demo.db`를 읽기 전용으로 연다. `demo.db`가 없거나 측정이 0건이면 빈 DB를 만들지 않고, 만드는 방법을 알려 주며 시작을 거부한다. `APP_MODE` 값은 앞뒤 공백과 대소문자를 무시하고, 모르는 값이면 로컬 모드로 넘어가지 않고 오류를 낸다
- USB 측정은 막고, `demo.db`에 담아 둔 실측과 합성 측정만 보여 준다. 403인 요청: 안테나 추가, 측정 저장(합성 샘플로 새로 만드는 것 포함), USB 측정, 업로드, 포트 목록, 장비 화면. 403 검사는 요청이 DB나 포트에 닿기 전에 한다
- LLM은 환경 변수와 관계없이 끈다(설명 버튼과 질문 입력칸을 숨긴다). 설명·질문 요청이 와도 LLM 부품을 부르지 않는다. `/api/health`는 `{"mode":"demo","ollama":false,"explain":false,"ports":[]}`
- 화면에 "시연 모드"를 표시한다. 측정 탭과 관리 탭, 사이드바의 "+ 안테나 추가"를 숨기고 이력에서 시작한다. 빈 화면 안내문도 숨긴 탭을 가리키지 않는다("측정 화면에서 시작해 주세요" 금지). 이름 수정과 삭제도 403이다
- 배지, 보이는 탭, 시작 탭, 안내문은 순수 함수 하나(`mode.ts`)가 정하고 컴포넌트는 그 결과만 그린다(렌더링 테스트 도구 없이 테스트한다). health 요청이 실패하면 측정 화면을 여는 대신 오류를 보여 준다
- `npm --prefix web run build` 결과를 FastAPI가 같은 주소에서 서빙한다
- `scripts/export_demo.py`: 현재 DB에서 고른 측정과 그 안테나만 id를 유지해 `demo.db`로 복사(로직은 `src/demo_export.py`). 인자 없이 실행하면 고를 수 있는 측정 목록을 보여 준다(1000건을 넘으면 잘렸다고 안내)
- 내보내기는 원본을 지킨다: 없는 id·중복 id·SQLite 범위를 넘는 id는 종료 코드 1이고 아무것도 쓰지 않는다. 출력이 원본과 같은 파일이면 거부하는데, 경로 문자열이 아니라 `samefile`로 비교한다(macOS에서 `ANTENNA.DB`는 `antenna.db`와 같은 파일이다). 새 임시 파일에 쓴 뒤 다 되면 교체하고, 지울 때는 자기가 만든 임시 파일만 지운다

이번에는 노트북에서 로컬로만 돌린다. **외부에 공개하지 않는다**(터널, 호스팅, 링크 만들기는 하지 않는다).

통과 검사: demo 모드 쓰기 403 테스트(안테나 추가, 측정 저장, 업로드, USB 측정 각각), `export_demo.py`로 만든 `demo.db`로 `APP_MODE=demo` 서버를 띄워 `http://localhost:8000`에서 "시연 모드" 표시와 카드가 보임. 대소문자만 다른 출력 이름과 하드 링크로 원본을 덮어쓰려는 경우, `APP_MODE=" Demo "`, 빈 `demo.db`도 테스트한다.

**확인용 서버는 비어 있는 포트에 띄운다.** 8000번에 이미 서버가 떠 있으면 그 서버에 쓰기 요청을 보내지 말고 다른 포트를 쓴다(리허설에서 시험 업로드가 실제 `antenna.db`에 저장됐다).
